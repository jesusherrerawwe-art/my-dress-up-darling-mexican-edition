## Dedicatoria

Para Jesús:

Esta historia fue creada especialmente para ti, con mucho cariño, admiración y la ilusión de compartir contigo una aventura que puedas disfrutar capítulo a capítulo. Que cada página te recuerde lo especial que eres y todos los buenos momentos que todavía nos quedan por vivir.

Espero que esta novela te saque una sonrisa, te sorprenda y se convierta en un pequeño recuerdo que puedas guardar con cariño. Gracias por ser una persona tan importante y por inspirar este proyecto desde el principio.

Con todo mi cariño,

— **Tsukikage (月影)**
